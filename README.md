# jurisfin-suspended

Page statique annoncant l'arret definitif du service JurisFin Assist (31 aout 2026).

Publiee via GitHub Pages sur le domaine `jurisfin.fr`. Elle porte les mentions legales
(LCEN art. 6-III) et les informations relatives au traitement des donnees personnelles
(RGPD), qui doivent rester accessibles apres la fermeture du service.

Aucune ressource externe, aucun script, aucun cookie, aucun traceur.

- `index.html` — la page
- `404.html` — copie conforme, pour que les anciennes URL indexees ne renvoient pas d'erreur
- `CNAME` — domaine personnalise GitHub Pages
